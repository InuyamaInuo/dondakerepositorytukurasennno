初学者の練習用として、簡易的なメモアプリをつくります。基本機能は以下の通りです。

現在の冷蔵庫の中身、作りたい献立、買い物リストの3種を編集できるようにします。

✅(実装完了)  冷蔵庫の中身リストは、食材の名称・量・カテゴリ(野菜、肉など)・買った日を状況に応じて随時更新できるようにします。
✅(実装完了)  このリストから、手動で選んだ食材を買い物リストに入れることができます。また、新しい食材が登録されたときの日付を自動で買った日として保存します(もちろん編集も可能)。
✅(実装完了)  カテゴリに応じて目安の賞味期限(「〇日」という値)を設定し、買った日-賞味期限を計算して数値が少なくなると期限切れが近づいているとして赤字になったり注意書きが出たりするようにします。
✅(実装完了、とりあえず30日延びる設定)  さらに、「冷凍済み」というチェックボックスにマークされている食材は、賞味期限が無限になる(または半年伸びる)ようにします。


✅(実装完了)  献立リストには、献立の名称・必要な食材とその量を登録します。
✅(実装完了)  献立登録・編集時、食材は自由に追加・削除ができますが、献立に食材が一つもない状態で登録・更新しようとするとエラーメッセージを出します。
✅(実装完了)  献立に食材を追加するとき、冷蔵庫リストに今まで入れたものを履歴として一覧で出してそこから選べるようにします。記憶しておける量は最大50件にします。
✅(実装完了)  現在の冷蔵庫の中身と比較して、足りない食材の下に赤文字で「(不足)」と記載します。
✅(実装完了)  また、今の冷蔵庫の中身で作れる献立(量が足りてなくてもOK)を、色を変えたり上のほうに表示したりして目立つようにします。
💣(不安定要素)献立編集時、食材を削除してから登録すると削除した分が空行になって残る場合がある。現状、削除・追加するたびに食材カラムのインデックスを更新することで対応。毎回は発生しないので原因不明。発生率高め。

✅(実装完了)  買い物リストには、食材名と量を表示します。
✅(実装完了)  冷蔵庫リストの上部に「買い物リストに加える」ボタンをつけて、クリックするとチェックボックスのついた食材を買い物リストに追加できます。
💥(ボタンは反応するが追加に失敗する。1行ずつしか追加できないUI)  手動でも食材を追加できるようにします。
献立リストからも、リストの各行に「作る」ボタンをつけ、クリックすると冷蔵庫リストの中身と比較して足りない食材を足りない分量だけ自動で買い物リストに入れるようにします。
なお、ほかのリストよりも簡単に編集できるようにしたいのでリストページの各行に削除ボタンをつけ、量もリストページからそのまま変更できるようにします)。
💥(値が保存されない)  編集したら、何もボタンとかを押さなくても自動で保存される仕様にします。
